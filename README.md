# Lab: Importing Data Sets - Used Cars Pricing

This repository contains a data analytics laboratory project focused on the foundational stages of the Data Science pipeline: data ingestion, initial inspection, and structural schema manipulation using automobile pricing data.

## 🎯 Project Objective

The goal of this lab is to practice the fundamentals of data engineering and exploratory data analysis (EDA). The project covers importing unstructured or unheaded data tables, assigning relational header schemas, performing basic data cleaning (such as handling missing headers or data types), and exporting the cleansed dataframe into structured formats for downstream statistical modeling.

## 📁 Repository Structure

* **`DA0101EN-Review-Introduction.ipynb`**: Interactive Jupyter Notebook containing the step-by-step walkthrough for data loading, index assigning, header manipulation, and dataframe previewing using the Pandas library.
* **`auto.csv`**: The raw comma-separated value (CSV) dataset containing comprehensive physical specifications and price points for various used vehicle models.

## 🛠 Technologies Used

* **Language:** Python 3.x
* **Core Environment:** Jupyter Notebooks
* **Data Manipulation Libraries:** Pandas, NumPy

## 🚀 Installation and Execution

### Local Environment Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   cd Lab-Importing-Data-Sets---Used-Cars-Pricing
   ```

2. **Install required analytics packages:**
   Make sure you have Pandas and Jupyter installed in your Python environment:
   ```bash
   pip install pandas notebook
   ```

3. **Launch the development environment:**
   ```bash
   jupyter notebook
   ```

4. **Run the analysis pipeline:**
   Open `DA0101EN-Review-Introduction.ipynb` from the Jupyter dashboard interface and run the code cells sequentially.

## 📈 Demonstrated Skills

* **Data Ingestion Engineering:** Loading raw, undocumented datasets from local storage or remote web resources into active runtime data structures.
* **Schema Definition & Mapping:** Programmatically injecting structural modifications, custom headers, and data types onto tabular structures to enforce relational schema definitions.
* **DataFrame Operations Mastery:** Utilizing advanced Pandas functionalities to slice data matrices, parse numerical subsets, identify null placeholders, and pipe clean objects back into portable file formats.
